## Agent Skills

Here, I share agent skills and other tools I use in various **non-development** workflows with AI agents. They live in two repositories:

### Content Skills — writing posts/articles with an AI agent

A skill system that takes a braindump or a draft to a finished article with the human in the loop at every gate: questions land in a Q&A file, feedback is markup inside the section files, and every AI pass is a git commit you can diff.

- **`go4content`**: Runs the creation pipeline — from a braindump (quick, or with fact research and an approved plan) or from your own draft — to section files with a title and subtitle.
- **`review4content`**: The AI marks up the text and scores it; you edit; the agent learns from your diff before the next part.

Clone [**the repository**](https://github.com/alexeye42/content-skills) as a ready writing workspace — it ships with the rules, a user profile to edit, and an example article.

### Workflow Skills

Meta-skills for process transparency and continuous improvement of agent behavior.

#### Git-Related Skills

- **`git-commit-flow`**: Commits AI-generated or human-edited content to git with a conventional message format (feat/fix with folder scope, prefixed with ai/human).
- **`git-diff-analyzer`**: Analyzes human edits to AI-generated content by comparing git commits, distilling patterns to iteratively improve agent skills.

#### Scrum-Inspired Skills

- **`task-file-updater`**: Automatically maintains short session briefs to track what was done and *why* decisions were made, ensuring transparency.
- **`issues-retrospective`**: Processes accumulated improvement files to detect recurring patterns and implement skill or rule changes.

For the complete collection of my workflow skills, visit [**this repository**](https://github.com/alexeye42/workflow-skills).
